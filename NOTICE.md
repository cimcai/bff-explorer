# Notices

This project implements browser-side TypeScript mechanics based on the public CuBFF implementation by Google LLC, published under the Apache License 2.0:

- https://github.com/paradigms-of-intelligence/cubff

The code in this repository is a fresh TypeScript implementation for an interactive web explorer, but the BFF operation semantics, 64-byte tape size, 128-byte pair execution buffer, 8192-step pair budget, and radius-2 2D interaction model are intentionally aligned with CuBFF and the associated Computational Life paper.
